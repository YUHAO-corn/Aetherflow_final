# 12-用户流程文档

## AI编写指南

本文档旨在详细描述AetherFlow产品中用户与系统的交互流程。作为AI，请遵循以下原则编写和更新本文档：

1. **结构化描述**：使用统一的格式描述每个用户流程，包括前置条件、步骤序列、数据流和异常处理
2. **全面覆盖**：确保涵盖所有平台（网页端、拓展端）的核心用户旅程
3. **详细步骤**：每个流程应包含足够详细的步骤，使开发人员能清晰理解实现需求
4. **数据流向**：明确标注数据在系统组件间的流动方向和传递内容
5. **异常处理**：描述每个流程中可能出现的异常情况及处理方法
6. **流程ID**：为每个流程分配唯一ID，格式为"Flow-[功能缩写]-[序号]"

在为新功能编写用户流程时，请参考已有流程的格式保持一致性，并确保与产品需求文档(11-产品需求文档.md)保持同步。

## 1. 文档概述

### 1.1 文档目的
本文档详细描述AetherFlow产品中用户与系统的交互流程，以及数据在不同组件间的流动路径，旨在帮助开发团队理解功能实现的完整过程。

### 1.2 用户旅程地图
AetherFlow产品的用户旅程围绕三个核心功能展开：
- **提示词快捷输入**：允许用户在AI平台输入框中快速调用已保存的提示词
- **提示词库管理**：提供提示词的存储、搜索和使用功能
- **提示词优化**：通过大语言模型API分析和改进提示词质量

### 1.3 轻量级使用模式
为了降低用户使用门槛，AetherFlow提供轻量级使用模式，允许用户在未登录状态下使用基本功能。

**流程ID**: Flow-LW-1  
**流程名称**: 轻量级使用模式  
**平台**: 浏览器拓展  

**特性**:
- 用户无需注册登录即可使用核心功能
- 数据仅存储在本地浏览器存储中，不进行云端同步
- 支持的功能包括提示词优化、基本提示词库管理和快捷输入
- 本地存储的提示词数量上限为50条

**主流程**:
1. 用户安装AetherFlow浏览器拓展
2. 用户首次打开拓展时，系统默认进入轻量级模式
   - 数据流: 拓展前端 → 本地存储
3. 系统在侧边栏顶部右边显示"登录"按钮
4. 用户可以直接使用提示词优化、提示词库和快捷输入功能
   - 所有数据操作只在本地存储中进行
   - 数据流: 拓展前端 ↔ 本地存储
5. 系统在适当位置显示升级提示，说明登录账户的额外好处（如云端同步、设备共享等）
6. 用户随时可点击"登录"按钮，升级为完整账户模式
   - 转换流程: 本地存储 → 用户认证 → 云端同步

**限制条件**:
- 本地存储的提示词上限为50条，超出时提示需要登录账户
- 不支持跨设备数据同步
- 清除浏览器数据会导致保存的提示词丢失

**异常处理**:
- 异常1: 存储空间不足
  - 触发条件: 浏览器本地存储空间已满
  - 处理方式: 提示用户清理数据或升级为账户模式
- 异常2: 数据升级冲突
  - 触发条件: 用户登录后，本地数据与云端数据存在冲突
  - 处理方式: 显示合并选项，允许用户选择保留本地版本、云端版本或两者合并

**验收标准**:
- 无账户状态下所有基本功能可用率>99%
- 本地数据操作响应时间<100ms
- 存储上限正确执行，超出时提示清晰
- 升级为账户模式的数据迁移成功率100%

## 2. 提示词快捷输入流程

### Flow-PS-1: 快捷指令调用提示词

**流程ID**: Flow-PS-1  
**流程名称**: 快捷指令调用提示词  
**平台**: 浏览器拓展  

**前置条件**:
- 用户已安装AetherFlow浏览器拓展
- 用户正在访问支持的AI平台页面（如ChatGPT）
- 提示词库中已有至少一个提示词（无论是本地存储还是云端）

**主流程**:
1. 用户在AI平台的输入框中输入"/"字符
2. 系统检测到"/"输入，激活快捷指令功能
3. 系统查询提示词库数据（本地存储优先，已登录用户同时检查云端）
   - 数据流: 拓展前端 → 本地存储/云端数据库 → 拓展前端
4. 系统在输入框上方显示下拉菜单，展示提示词列表
5. 用户在"/"后继续输入关键词
6. 系统实时过滤提示词列表，仅显示包含关键词的提示词
   - 数据流: 用户输入 → 拓展前端 → 过滤逻辑 → 拓展前端
7. 系统按"收藏>高频使用>低频使用"顺序排序结果
8. 用户通过鼠标点击或键盘上下键选择目标提示词
9. 用户按Enter键或点击确认选择的提示词
10. 系统将选中的完整提示词内容插入到输入框中，替换"/关键词"
    - 数据流: 拓展前端 → AI平台输入框
11. 系统更新该提示词的使用频率数据
    - 数据流: 拓展前端 → 本地存储 → (如已登录)云端同步

**异常处理**:
- 异常1: 无匹配结果
  - 触发条件: 用户输入的关键词在提示词库中没有匹配项
  - 处理方式: 显示"未找到匹配项"消息，不影响用户继续输入
- 异常2: 网络连接失败
  - 触发条件: 已登录用户网络异常无法连接云端
  - 处理方式: 仅使用本地缓存数据，显示"使用本地数据"提示
- 异常3: 页面焦点丢失
  - 触发条件: 用户在选择提示词过程中点击页面其他区域
  - 处理方式: 关闭下拉菜单，保留用户已输入内容

**验收标准**:
- 下拉菜单响应时间<200ms
- 最多显示10个匹配结果
- 排序逻辑正确应用

## 3. 提示词库管理流程

### Flow-PL-1: 浏览和使用提示词库

**流程ID**: Flow-PL-1  
**流程名称**: 浏览和使用提示词库 
**平台**: 浏览器拓展  

**前置条件**:
- 用户已安装AetherFlow浏览器拓展
- 用户打开了拓展侧边栏

**主流程**:
1. 用户点击浏览器工具栏中的AetherFlow图标或使用快捷键(Ctrl+Shift+E)
2. 系统在页面右侧显示AetherFlow侧边栏
3. 用户点击侧边栏中的"提示词库"
4. 系统加载提示词库数据（本地存储或云端，取决于登录状态）
   - 数据流: 拓展前端 → 本地存储/云端数据库 → 拓展前端
5. 系统以卡片形式展示提示词，默认按存储时间倒序排列
6. 用户可执行以下操作：
   - **搜索**: 在搜索框中输入关键词，系统实时过滤显示结果
   - **排序**: 选择使用频率/收藏状态/存储时间排序方式
   - **查看详情**: 点击卡片展开完整内容
   - **复制提示词**: 点击"复制"将提示词内容复制到剪贴板
   - **收藏/取消收藏**: 点击收藏图标标记重要提示词
   - **删除**: 长按或点击删除图标移除提示词
7. 系统根据操作实时更新界面和存储数据
   - 数据流: 用户操作 → 拓展前端 → 本地存储 → (如已登录)云端同步

**数据操作流程**:
- **插入操作**: 拓展前端 → 页面内容脚本 → AI平台输入框
- **复制操作**: 拓展前端 → 系统剪贴板
- **收藏操作**: 拓展前端 → 本地存储 → (如已登录)云端同步
- **删除操作**: 拓展前端 → 本地存储 → (如已登录)云端同步

**异常处理**:
- 异常1: 数据加载失败
  - 触发条件: 网络问题或数据库异常
  - 处理方式: 显示错误提示，提供重试选项，尝试加载本地缓存
- 异常2: 提示词库为空
  - 触发条件: 新用户或已删除所有提示词
  - 处理方式: 显示引导提示，建议如何添加和保存提示词
- 异常3: 插入失败
  - 触发条件: 当前页面不是支持的AI平台或输入框不可访问
  - 处理方式: 显示错误提示，引导用户复制内容

**验收标准**:
- 提示词库加载时间<1秒（100条提示词情况下）
- 搜索功能响应时间<300ms
- 插入和复制功能成功率>99%
- 侧边栏调整（大小/位置）流畅度高

## 4. 提示词优化流程

### Flow-PE-1: 提示词优化与分析

**流程ID**: Flow-PE-1  
**流程名称**: 提示词优化与分析  
**平台**: 浏览器拓展  

**前置条件**:
- 用户已安装AetherFlow浏览器拓展
- 用户已打开提示词优化功能界面

**主流程**:
1. 用户在拓展侧边栏点击"提示词优化"选项
2. 系统显示提示词优化界面，包含输入框和操作按钮
   - 数据流: 用户操作 → 拓展前端
3. 用户在输入框中输入或粘贴原始提示词（v0版本）
4. 用户点击"优化"按钮
5. 系统立即生成新卡片占位并播放等待动效，提供流畅自然的加载体验
   - 数据流: 用户操作 → 拓展前端
6. 系统调用大语言模型API，发送优化请求
   - 数据流: 拓展前端 → 后端API → 大语言模型API
7. 系统接收优化后的提示词
   - 数据流: 大语言模型API → 后端API → 拓展前端
8. 系统以动态效果显示优化后的提示词，并创建新的提示词卡片（v1版本）
9. 卡片上显示优化后的提示词内容，并提供收藏按钮和复制按钮
10. 用户可点击卡片查看完整优化内容
11. 用户可点击"继续优化"按钮，进一步改进当前版本
12. 系统重复步骤5-9，创建新的优化版本卡片（v2版本）
    - 数据流: 用户操作 → 拓展前端 → 后端API → 大语言模型API → 后端API → 拓展前端
13. 用户可以点击任意版本的卡片（如v1），然后点击"继续优化"
14. 系统基于选中的卡片内容生成新的优化版本，并插入到该卡片之后
    - 示例：用户点击v3卡片继续优化，新卡片将插入在v3和v4之间
15. 用户可以编辑任意卡片的提示词内容
16. 用户可以通过两种方式将优化结果添加到提示词库：
    - 方式1: 点击卡片上的收藏按钮
      - 数据流: 用户操作 → 拓展前端 → 本地存储 → 云端同步
    - 方式2: 将卡片拖拽至提示词库导航图标并松开
      - 数据流: 用户操作 → 拓展前端 → 本地存储 → 云端同步
17. 用户可以点击卡片上的复制按钮，将优化内容复制到剪贴板
    - 数据流: 用户操作 → 拓展前端 → 系统剪贴板

**限制条件**:
- 系统最多容纳10张优化卡片，达到上限后用户继续优化会收到"已达到最大优化次数"提示
- 每次在输入框重新开始优化操作时，系统会清空当前所有优化历史

**异常处理**:
- 异常1: API调用失败
  - 触发条件: 网络问题或后端服务不可用
  - 处理方式: 显示错误提示，提供重试选项，保留已生成的卡片占位，并允许用户保存当前输入
- 异常2: 输入提示词过短或不完整
  - 触发条件: 用户输入的提示词少于10个字符
  - 处理方式: 显示警告提示，建议用户提供更完整的提示词以获得更好的优化效果
- 异常3: 优化超时
  - 触发条件: 优化请求超过30秒未返回结果
  - 处理方式: 显示超时提示，询问用户是否继续等待或取消请求

**验收标准**:
- 优化请求响应时间<5秒
- 卡片占位和加载动效流畅自然，无卡顿现象
- 非线性优化路径（插入卡片）功能正确率100%
- 拖拽收藏功能成功率>99%
- 复制功能成功率100%

## 5. 模块交互流程

### Flow-MI-1: 优化结果保存至提示词库

**流程ID**: Flow-MI-1  
**流程名称**: 优化结果保存至提示词库  
**平台**: 浏览器拓展  

**前置条件**:
- 用户已完成至少一次提示词优化
- 优化界面中至少有一张提示词卡片

**主流程**:
1. **方式一：点击收藏按钮**
   1. 用户在优化卡片上点击收藏按钮
   2. 系统将优化后的提示词保存至提示词库
      - 数据流: 拓展前端 → 本地存储 → (如已登录)云端同步
   6. 系统显示"已添加到提示词库"成功提示
   7. 提示词库中的条目计数增加
2. **方式二：拖拽至提示词库图标**
   1. 用户按下鼠标开始拖拽优化卡片
   2. 系统创建卡片缩略视图随鼠标移动
   3. 用户将卡片拖拽至提示词库导航图标上
   4. 系统在图标周围显示高亮提示，表示可释放区域
   5. 用户松开鼠标按钮
   6. 后续步骤同方式一的2-7步

**异常处理**:
- 异常1: 拖拽偏离目标
  - 触发条件: 用户拖拽卡片未到达提示词库图标有效区域即松开
  - 处理方式: 系统取消拖拽操作，卡片动画返回原位
- 异常2: 存储失败
  - 触发条件: 存储服务异常
  - 处理方式: 系统显示错误提示，建议用户重试或使用复制功能保存内容
- 异常3: 已达到轻量级模式存储上限
  - 触发条件: 未登录用户本地存储达到50条上限
  - 处理方式: 显示升级提示，建议用户登录账户获得更多存储空间

**验收标准**:
- 保存操作响应时间<500ms
- 弹窗响应时间<200ms
- 拖拽操作流畅自然，视觉反馈明确
- 存储成功率>99%

### Flow-MI-2: 从提示词库到快捷输入的数据流转

**流程ID**: Flow-MI-2  
**流程名称**: 提示词库到快捷输入的数据流转  
**平台**: 浏览器拓展  

**前置条件**:
- 用户已安装AetherFlow浏览器拓展
- 提示词库中已有提示词内容

**主流程**:
1. 系统在后台持续监听用户在提示词库的操作
2. 用户在提示词库中进行的收藏、使用频率变化等操作会自动影响快捷输入功能的排序
   - 数据流: 提示词库操作 → 本地存储/云端数据库 → 快捷输入功能
3. 当用户使用"/"快捷指令时，系统根据提示词库中的数据状态（收藏状态、使用频率）动态生成推荐排序
4. 系统确保两个功能模块间的数据一致性，任何一方的更新都会实时反映在另一方

**异常处理**:
- 异常1: 数据不一致
  - 触发条件: 本地存储与云端数据存在冲突
  - 处理方式: 系统以云端数据为准，同时在后台自动解决冲突
- 异常2: 同步延迟
  - 触发条件: 网络延迟导致云端同步滞后
  - 处理方式: 显示"同步中"状态指示器，同时允许用户继续使用本地数据

**验收标准**:
- 数据一致性保证率>99%
- 模块间数据同步时间<3秒
- 用户体验无明显延迟或中断
