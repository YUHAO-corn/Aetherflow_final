# CRISPE框架使用指南

## 什么是CRISPE框架？

CRISPE框架是一种系统化的提示词工程方法，旨在创建更高质量、更结构化的AI提示词。该框架被集成到了AetherFlow的提示词优化功能中，特别是在"标准模式"下使用。

CRISPE是以下六个关键元素的首字母缩写：

- **C - 能力和角色**（Capability and Role）：AI应扮演的角色或发挥的能力
- **R - 要求**（Requirements）：具体任务要求和约束条件
- **I - 意图**（Intention）：用户的真实目的和期望达成的目标
- **S - 特定风格**（Specific Style）：输出的风格和格式要求
- **P - 个性化**（Personality）：AI应表现的语气和个性特征
- **E - 评估标准**（Evaluation Criteria）：评判成功输出的标准

## 为什么使用CRISPE框架？

使用CRISPE框架进行提示词优化有以下显著优势：

1. **系统化思考**：不再遗漏提示词的关键组成部分
2. **结构清晰**：优化后的提示词结构更加清晰，条理分明
3. **针对性强**：每个组成部分都有明确的目标和作用
4. **效果可预测**：遵循框架的提示词通常能获得更一致的AI回应
5. **适应性好**：框架适用于各种领域和复杂度的提示词

## 如何使用优化后的提示词

通过AetherFlow的提示词优化功能（标准模式）优化后的提示词通常会包含CRISPE框架的多个元素。以下是如何有效使用这些优化结果：

1. **理解结构**：优化后的提示词会有明确的结构，可能包含角色设定、具体要求、输出格式等
2. **按需调整**：根据实际需求，可以手动修改优化结果中的特定部分
3. **保留核心组件**：即使修改，也建议保留CRISPE框架的核心组件，特别是角色定义和具体要求
4. **迭代优化**：可以基于优化结果再次使用"继续优化"功能，进行多轮优化

## 示例展示

### 原始提示词

```
介绍人工智能
```

### 优化后的提示词（应用CRISPE框架）

```
请作为一名人工智能教育专家(C)，提供一篇关于人工智能的全面介绍。我需要了解AI的基本概念、历史发展、主要技术类型和现实应用(R)。这将帮助我建立对AI领域的基础认识，并了解其对社会的影响(I)。

请以教学风格呈现内容，由浅入深，使用清晰的结构和通俗易懂的语言(S)。保持客观专业的态度，同时表现出对技术进步的热情(P)。

一个优质的回答应包含：
- 人工智能的准确定义和核心概念
- 发展历程中的关键里程碑
- 主要AI类型的区别和特点
- 至少3个不同领域的实际应用案例
- 对未来发展趋势的简要展望(E)
```

## 最佳实践提示

1. **不必应用全部元素**：并非所有提示词都需要完整的CRISPE框架，可以根据具体情况选择最相关的部分
2. **保持简洁**：虽然框架提供了全面的结构，但避免提示词过于冗长，每个部分应简明扼要
3. **特定领域调整**：针对特定领域（如编程、写作、数据分析）的提示词，可以添加该领域特有的专业术语和结构
4. **结合其他模式**：对于特定需求，可以先用标准模式获得结构化提示词，然后再用创意模式或简洁模式进一步优化

## 常见问题

**问**：是否所有提示词都适合使用CRISPE框架？  
**答**：不是。简单的事实型查询可能不需要完整框架。CRISPE框架最适合复杂任务、创意生成、专业分析等场景。

**问**：优化后的提示词是否太长？  
**答**：框架会根据原始提示词的复杂度自动调整优化深度。对于简单提示词，不会应用全部元素，保持结果简洁。

**问**：如何知道优化效果如何？  
**答**：使用优化后的提示词与原始提示词分别向AI提问，比较回答质量。通常，使用CRISPE框架的提示词会获得更全面、更符合预期的回答。
